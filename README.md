# Entrepreneurial Skills – EntreComp wheel

An interactive wheel presenting the 15 competences of the European Entrepreneurship Competence Framework (EntreComp), grouped into three areas: *Ideas & opportunities*, *Resources* and *Into action*. Click a segment to read a short description of each competence.

**Live version:** https://margret292-prog.github.io/Enterpreneurial-skills/

Descriptions are based on [EntreComp: A Practical Guide](https://entrecompeurope.eu/wp-content/uploads/EntreComp-A-Practical-Guide-English.pdf) (McCallum et al., 2018, CC BY 4.0).

A Norwegian version is available at https://margret292-prog.github.io/Entrepren-rielle-ferdigheter/
